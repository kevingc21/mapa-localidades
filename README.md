# Mapa de localidades

Página web (un solo archivo HTML, sin dependencias) para catalogar los lugares de un mapa de Minecraft por regiones.

## Uso
1. Abre `index.html` en el navegador (doble clic) o publícalo con GitHub Pages.
2. Elige una región y carga su imagen.
3. Cambia a **Modo: Editar** y haz clic en el mapa para añadir lugares.
4. Exporta tus lugares a JSON o CSV desde la sección "Exportar / importar".

## Notas
- Los lugares, las imágenes y los vínculos se guardan en el navegador (localStorage / IndexedDB).
- Exporta un JSON de respaldo de vez en cuando.
